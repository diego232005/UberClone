Documentación de asistencia con herramientas de inteligencia artificial en el proyecto **UberClone — Versión Conductor**, según el instructivo del curso.

La bitácora completa está en:

**[AI_LOG.md](./AI_LOG.md)**

## Entrega

1. Mantener `docs/AI_LOG.md` en la rama `main` / `master`.
2. Enlace desde el [README del proyecto](../README.md) (sección **Uso de IA**).
3. Exportar este contenido a **PDF** (`docs/AI_LOG.pdf`) para la plataforma de entrega.
4. En el código, bloques asistidos marcados con:
   `// AI-assisted: see docs/AI_LOG.md #N`
